# 만나의 식탁 영상 제작실

`/videos/studio`에서 레시피를 불러오고 장면별 글을 편집합니다. 긴 글은 자동으로 나뉘며,
사이트의 음식별 색상·지역에서 영감 받은 문양과 부드러운 전환을 담은 영상을 브라우저에서 만듭니다.
하단 자막은 포함하거나 끌 수 있습니다. 가로 16:9와 세로 9:16을 지원하며 최대 10분입니다.

저장 화질은 **4K UHD가 기본**이며 1440p QHD, 1080p Full HD로 바꿀 수 있습니다.

| 화질 | 가로 | 세로 |
| --- | --- | --- |
| 4K UHD | 3840 × 2160 | 2160 × 3840 |
| 1440p QHD | 2560 × 1440 | 1440 × 2560 |
| 1080p Full HD | 1920 × 1080 | 1080 × 1920 |

모든 화질은 30fps입니다. 글자와 도형을 선택한 출력 해상도로 직접 그려 저장합니다.
편집 중 미리 보기는 부드러운 재생을 위해 1080p 캔버스를 사용하며, 구도와 자막 설정은 저장 영상과 같습니다.
선택한 화질을 브라우저가 지원하지 않으면 안내를 표시합니다. 자동으로 해상도를 낮춰 저장하지 않습니다.

## AI 음성 연결

OpenAI 한국어 내레이션을 지원합니다. Vercel 프로젝트의 Settings → Environment Variables에
아래 두 값을 **서버 전용 · Production 환경**으로 등록한 뒤 재배포합니다.
로컬에서는 `.env.local`에 넣고 개발 서버를 다시 시작합니다.

| 이름 | 값 |
| --- | --- |
| `OPENAI_API_KEY` | 음성 모델 사용 권한이 있는 OpenAI의 실제 비밀키 (`sk-`로 시작) |
| `VIDEO_STUDIO_PASSWORD` | 16~256자의 무작위 제작실 비밀번호 |

비밀 값은 저장소에 커밋하거나 `NEXT_PUBLIC_` 접두사를 붙이지 않습니다.
API 키는 화면에 입력하지 않고 서버 설정에만 등록합니다. 제작실 화면에는 제작실 비밀번호만 입력합니다.
키·비밀번호는 대화에 보내지 않습니다. `key_`로 시작하는 Tracking ID는 키를 식별하는 값이며 인증에 사용할 수 없습니다.
비밀키를 잃어버렸다면 [OpenAI API keys](https://platform.openai.com/api-keys)에서 새로 발급받아 서버에 등록합니다.
화면의 **OpenAI 음성 설정됨**은 서버 설정이 존재한다는 뜻입니다. 실제 키 권한·잔액·발음은 첫 장면 생성으로 확인합니다.

서버는 OpenAI Realtime API의 `gpt-realtime-2.1-mini`와 `marin` 목소리를 사용합니다.
2026-10-29에 확인한 공식 지침에 따라, 종료 예정인 Speech API 대신 신규 연동에 권장되는 Realtime API를 사용합니다.
각 장면의 대본을 읽도록 한국어 지침을 보내며 마이크 입력이나 대화 기능은 사용하지 않습니다.
24 kHz 모노 PCM 음성을 모아 완성된 WAV로 전달합니다. 비밀키는 브라우저로 보내지 않습니다.
Realtime은 문자별 시간을 제공하지 않으므로 **자막 시간 추정**이 표시됩니다.
생성된 음성이 원문을 정확히 읽었는지, 특히 재료량·온도·시간·부정 표현과 발음을 저장 전에 들어서 확인합니다.

음성은 AI 합성 음성이며, 생성 버튼을 누르면 대본이 해당 음성 서비스로 전송됩니다.
API 사용료가 발생할 수 있습니다. **첫 장면 음성만 만들어 보기**로 먼저 확인한 뒤 나머지를 생성할 수 있습니다.
실패 시 자동 재시도하거나 다른 유료 서비스로 전환하지 않습니다.
API 잔액이나 권한이 부족하면 설정을 확인하라는 안내를 표시합니다. ChatGPT 구독과 별도로 API 계정의 잔액·사용 한도를 확인합니다.

기존 ElevenLabs 설정도 유지할 수 있습니다. `OPENAI_API_KEY`가 없을 때만
`ELEVENLABS_API_KEY`와 `ELEVENLABS_VOICE_ID`를 사용합니다. 제작실 비밀번호는 동일하게 필요합니다.
기존 방식은 `eleven_multilingual_v2`와 `/with-timestamps`를 사용하며 문자별 시간이 유효할 때 자막에 반영합니다.
두 서비스가 모두 설정되어 있으면 OpenAI가 우선합니다. ElevenLabs 목소리의 이용 권한은 해당 계정 조건을 따릅니다.

- [OpenAI 음성 생성 안내 및 이전 경로](https://developers.openai.com/api/docs/guides/text-to-speech)
- [OpenAI Realtime 대화와 음성 출력](https://developers.openai.com/api/docs/guides/realtime-conversations)
- [OpenAI Realtime Mini 모델](https://developers.openai.com/api/docs/models/gpt-realtime-2.1-mini)
- [ElevenLabs 음성 생성과 이용 권한](https://elevenlabs.io/docs/overview/capabilities/text-to-speech)
- [문자별 시간 정보 API](https://elevenlabs.io/docs/api-reference/text-to-speech/convert-with-timestamps)

## 제작과 저장

1. 레시피와 구성을 선택한 뒤 불러옵니다. 식문화 이야기 또는 조리법까지 포함한 전체 구성을 고를 수 있습니다.
2. 장면별 제목·글을 수정하고 가로/세로 비율, 저장 화질, 하단 자막 포함 여부를 정합니다. 추가·삭제할 수 있으며, 기존 출처는 마지막 화면에 남습니다.
3. 연결 후 비밀번호를 입력하고 첫 장면의 한국어 음성을 만들어 들어봅니다. 확인 후 남은 내레이션을 생성합니다. 실패하면 자동 재요청하지 않으며 완성된 장면은 현재 탭에 남습니다.
4. 재생해 확인한 뒤 음성 포함 영상 또는 무음 영상을 만듭니다. 완성된 영상은 화면에서 확인하고 내려받습니다.
5. 필요하면 자막 SRT와 원문 출처 URL을 포함한 대본 TXT도 저장합니다. 자막 없는 영상에서도 SRT는 별도로 저장할 수 있습니다.

‘자막 없이’는 하단 내레이션 자막을 숨깁니다. 장면의 제목, 레시피 본문, 출처는 그대로 표시됩니다.
음성 포함 여부와 자막 포함 여부는 각각 선택할 수 있습니다.

API 연결 전에도 무음 영상 제작은 가능합니다. 음성이 완성되지 않은 프로젝트를 음성 포함 영상으로 저장할 수는 없습니다.
음성이 없는 자막은 글 길이로 시간을 추정합니다. 각 영상에 표시되는 자막과 내려받은 SRT의 시간은 같습니다.
음성을 수정한 뒤에는 해당 대본의 음성을 다시 생성해야 합니다. 같은 글의 음성은 현재 탭에서 재사용합니다.

영상 인코딩은 [Mediabunny](https://mediabunny.dev/guide/writing-media-files)로 브라우저 안에서 처리합니다.
MP4(H.264/AAC)를 우선 사용하며 지원하지 않으면 WebM(VP9/Opus)을 확인합니다.
WebCodecs를 지원하는 최신 데스크톱 Chrome 또는 Edge를 권장합니다.
기기 성능에 따라 제작 시간이 달라지고, 긴 영상과 고화질 영상은 메모리를 많이 사용합니다. 완료될 때까지 탭을 열어 둡니다.
사이트의 일반 화면을 캡처하는 방식이 아니라 같은 디자인으로 영상 프레임을 그리므로 브라우저 도구막대가 포함되지 않습니다.

대본·음성·완성 영상은 서버에 보관하지 않습니다. 현재 탭을 닫거나 새로고침하기 전 파일로 저장하세요.
유튜브 자동 업로드와 정기 실행은 포함하지 않습니다.

## 검증

`npm run check:video`는 모든 레시피의 원문 보존, 자막 타이밍, 출처 보존,
API 인증과 요청 크기 제한을 확인합니다. OpenAI 스트림의 WAV 변환, 잘린 음성 거절,
오류·연결 중단 처리, 자동 재시도 방지와 기존 ElevenLabs 방식도 검사합니다.
외부 음성 API는 모의 응답을 사용해 유료 호출을 하지 않습니다.
실제 목소리의 발음과 유료 계정 연결은 운영자가 환경 변수를 등록한 뒤 짧은 대본으로 확인합니다.
